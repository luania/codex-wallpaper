# Pixiv 背景

需要 Node.js 24+。

通过 pixivflow 下载最新插画月榜，排除 H 图和明显擦边内容后取过滤榜单前 100 个作品：

```sh
pnpm download:monthly-safe-top100
```

命令执行时读取最新榜单并逐页筛选，每个作品只保存第一张原图到 `downloads/`，作品清单保存为 `downloads/ranking-monthly-safe-top100.json`。过滤会排除漫画、动图、被遮罩或有性内容标记的作品，以及标题或标签包含裸露、内衣、泳装、性暗示等关键词的作品。不足 100 个时会报错并停止，不会启动图片下载。

下载当前最新发布的 Pixiv 日榜图片：

```sh
pnpm download
# 等价于 node download.ts
```

图片按本机下载日期保存到项目的 `imgs/YYYY-MM-DD/`，文件名前的数字保留榜单顺序。同一天重复下载会覆盖同名文件，其他日期目录保留。Pixiv 最新发布的日榜日期可能是前一天；原图片域名连接失败时会尝试公开镜像 `i.pixiv.re`。

下载指定画师的全部插画作品（包括多页作品）：

```sh
pnpm download:artist 123456
pnpm download:artist https://www.pixiv.net/users/123456
pnpm download:artist --user 123456 --output ./downloads/my-artist
```

默认保存到 `downloads/artists/<画师 ID>/`。命令会读取 `pixivflow-ranking.config.json` 中的 Pixiv 登录配置，也可以通过 `--config <路径>` 指定其他配置文件；每个画师使用独立的 PixivFlow 下载记录，重复执行会跳过已完成作品。

启动带调试端口的应用，然后注入本地图片：

```sh
pnpm start
# 等应用启动完成后运行
pnpm inject
# 只注入 downloads/ 下指定子目录的图片
pnpm inject artists/1554775/artists/1554775
```

注入命令默认递归扫描项目 `downloads/` 目录（包括画师下载生成的子目录）。可用 `pnpm inject <子目录>` 只扫描指定目录及其子目录；路径相对于 `downloads/`，无需添加 `downloads/` 前缀，不支持绝对路径或跳出 `downloads/`。命令只读取图片头部获取尺寸，不读取完整图片内容，也不注入 Base64；它把图片转换为 `http://127.0.0.1:5500/downloads/...` URL（保留完整子目录路径），由已启动的 Live Server 在页面轮替时提供图片。Node 无法读取尺寸的文件会回退到浏览器解码，仍然只在需要显示或分类时加载。

支持 JPG/JPEG、PNG、WebP、GIF、AVIF、BMP 和 SVG，按相对路径自然排序。注入时会从图片头部读取实际尺寸：宽度大于或等于高度的图片归为横图，其他图片归为竖图；正方形按横图处理。窗口横向时只从横图中选择，窗口竖向时只从竖图中选择；某一方向没有图片时回退到另一方向。窗口方向改变会立即切换图片，图片轮替使用约 500ms 淡入淡出过渡；同一方向内调整窗口大小不会切图。Node 读取尺寸最多并发 16 个；无法读取尺寸的图片回退到浏览器，回退分类最多并发 4 张，每张最多等待 15 秒。

注入完成后程序退出，页面每分钟轮替。以下快捷键在 Mac 上使用 `⌘ + Option`，其他系统使用 `Ctrl + Alt`：

| 按键 | 功能 |
| --- | --- |
| `→` | 切换下一张并重新计时 |
| `Space` | 切换前景图显示/隐藏 |
| `↑` | 增加模糊值 1 px |
| `↓` | 减少模糊值 1 px，最低为 0 px |
| `滚轮 ↑` | 增加不透明度 0.01 |
| `滚轮 ↓` | 减少不透明度 0.01，最低为 0 |
| `C` | 复制当前图片地址 |

模糊值初始为 0 px，无额外上限；支持长按上下箭头连续调整。不透明度初始为 0.2，范围为 0 到 1，每个滚轮事件调整 0.01。切图、窗口方向变化、隐藏再显示时均保留当前模糊值和不透明度；单张图片或隐藏状态下也可调整，调整不会触发切图或重置轮替计时。重新注入或刷新后重置为默认值；刷新页面后需要重新注入。

调整模糊值或不透明度时，右下角会短暂显示当前值；按 `C` 复制图片地址后会短暂显示“已复制”。
