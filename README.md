# Pixiv 背景

需要 Node.js 24+。

通过 pixivflow 下载最新插画月榜，排除 H 图和明显擦边内容后取过滤榜单前 100 个作品：

```sh
pnpm download:monthly-safe-top100
```

命令执行时读取最新榜单并逐页筛选，每个作品只保存第一张原图到 `downloads/`，作品清单保存为 `downloads/ranking-monthly-safe-top100.json`。过滤会排除漫画、动图、被遮罩或有性内容标记的作品，以及标题或标签包含裸露、内衣、泳装、性暗示等关键词的作品。不足 100 个时会报错并停止，不会启动图片下载。

下载当前最新发布的 Pixiv 日榜图片：

```sh
pnpm download
# 等价于 node download.ts
```

图片按本机下载日期保存到项目的 `imgs/YYYY-MM-DD/`，文件名前的数字保留榜单顺序。同一天重复下载会覆盖同名文件，其他日期目录保留。Pixiv 最新发布的日榜日期可能是前一天；原图片域名连接失败时会尝试公开镜像 `i.pixiv.re`。

下载指定画师的全部插画作品（包括多页作品）：

```sh
pnpm download:artist 123456
pnpm download:artist https://www.pixiv.net/users/123456
pnpm download:artist --user 123456 --output ./downloads/my-artist
```

默认保存到 `downloads/artists/<画师 ID>/`。命令会读取 `pixivflow-ranking.config.json` 中的 Pixiv 登录配置，也可以通过 `--config <路径>` 指定其他配置文件；每个画师使用独立的 PixivFlow 下载记录，重复执行会跳过已完成作品。

启动带调试端口的应用，然后注入本地图片：

```sh
pnpm start
# 等应用启动完成后运行
pnpm inject
# 只注入 downloads/ 下指定子目录的图片
pnpm inject artists/1554775/artists/1554775
```

注入命令默认选择项目 `downloads/` 目录（包括画师下载生成的子目录）。可用 `pnpm inject <子目录>` 只选择指定目录及其子目录；路径相对于 `downloads/`，无需添加 `downloads/` 前缀，不支持绝对路径或跳出 `downloads/`。命令会先在 Node 中使用 `image-size` 读取图片头部和尺寸，再通过 Playwright 向页面插入隐藏的目录选择 `input`，自动选择目标目录。页面读取 `File` 对象并按需创建 `blob:` URL；不需要启动 Live Server 或其他文件服务。

支持 JPG/JPEG、PNG、WebP、GIF、AVIF、BMP 和 SVG，按 `webkitRelativePath` 自然排序。Node 会读取图片头部获取尺寸：宽度大于或等于高度的图片归为横图，其他图片归为竖图；正方形按横图处理。正常图片只在首次显示或轮替到它时由页面解码；Node 无法读取尺寸的图片会在实际使用时回退到浏览器判断。窗口横向时只从横图中选择，窗口竖向时只从竖图中选择；某一方向没有图片时回退到另一方向。窗口方向改变会立即切换图片，默认使用 1000ms 淡入淡出过渡；同一方向内调整窗口大小不会切图。无法解码的图片会被跳过，每张图片最多等待 15 秒。图片 `blob:` URL 也只在需要显示时创建，并在切换后回收。

注入完成后程序退出，页面默认每 5 分钟轮替；底部细进度线会从每次切图完成后开始推进，填满后进入下一次轮替，当前方向只有一张可用图片或关闭自动轮替时隐藏。页面会在当前注入会话中保留最近 20 张之前显示过的图片，刷新或重新注入后清空。注入同时安装纯享模式：鼠标和键盘连续 30 秒没有活动时，只保留主对话内容；鼠标点击会恢复界面。按 `⌘/Ctrl + Alt + ,` 打开设置面板，修改即时生效并保存到当前浏览器页面的 `localStorage`；重新执行 `pnpm inject` 会继续使用上次设置。面板中的“恢复默认”会恢复以下默认值和快捷键：

| 按键 | 功能 |
| --- | --- |
| `⌘/Ctrl + Alt + →` | 历史中前进；到最新记录后随机切换并重新计时 |
| `⌘/Ctrl + Alt + ←` | 回看上一张历史图片，最多保留 20 张 |
| `⌘/Ctrl + Alt + Space` | 切换前景图显示/隐藏 |
| `⌘/Ctrl + Alt + ↑` | 增加模糊值 1 px |
| `⌘/Ctrl + Alt + ↓` | 减少模糊值 1 px，最低为 0 px |
| `⌘/Ctrl + Alt + PageUp/PageDown` | 增加/减少不透明度 0.01 |
| `⌘/Ctrl + Alt + C` | 复制当前图片相对路径 |
| `F5` 按住 | 临时查看当前图片原图，松开后恢复效果 |
| `F4` 双击 | 立即开关纯享模式；退出后重新开始 30 秒空闲计时 |
| `F4` 按住 | 纯享模式中暂时显示完整界面，松开后恢复 |

面板可配置自动轮替开关、轮替间隔（10 秒到 1 小时）、淡入淡出时长、模糊值（0 到 500 px）、不透明度（0 到 100%）、前景图显示状态、纯享模式自动进入和空闲时间（5 秒到 10 分钟），以及上表所有快捷键。快捷键按 `code + Primary/Alt/Shift` 记录；`Primary` 在 macOS 使用 Command，在 Windows/Linux 使用 Ctrl。录入时如果与其他动作冲突会拒绝保存并提示。模糊值初始为 0 px，支持长按上下箭头连续调整；不透明度初始为 0.33，滚轮仍可按 0.01 调整。切图、窗口方向变化、隐藏再显示时均保留当前模糊值和不透明度；单张图片或隐藏状态下也可调整，调整不会触发切图或重置轮替计时。

调整模糊值或不透明度时，右下角会短暂显示当前值；按 `C` 复制图片相对路径后会短暂显示“已复制”。

纯享模式默认使用双击 `F4` 开关，按住单独的 `F4` 会暂时显示完整界面，松开后恢复；两次按下间隔超过约 300ms 时按单次按住处理。退出后会重新开始完整的 30 秒计时。关闭“空闲自动进入”后不会再启动计时器；修改空闲时间会从当前时刻重新计时。开启时通过 `body._pure-mode_` 控制样式，隐藏主区域之外的 UI 和浮动导航列表，保留主显示区域及其全部元素。鼠标点击不会退出纯享模式。主区域、Composer 菜单和已打开的设置面板保持可见；隐藏和恢复使用约 200ms 的淡变效果。设置使用版本化键 `__pixiv_inject_settings_v1__` 保存，只在当前浏览器配置的同源页面中生效。刷新页面后仍需重新执行 `pnpm inject`。
